# 🏦 Bank Account Management (Console)

A console program in **core Java** that manages bank accounts – a practice task from my Java learning journey.

## Features
- Open an account and show account details
- Deposit and withdraw with balance checks
- Search accounts by account number

## Structure
`src/java/util/Scanner/BankDetails.java` – the `BankDetails` class with open, show, deposit, withdraw and search operations.

**Concepts practised:** classes & objects, arrays of objects, menu-driven programs, `Scanner` input.
